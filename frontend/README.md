This directory will contain the React + Vite + Tailwind CSS frontend for the LeadPulse AI dashboard.

## Setup (coming soon)

```bash
bun install

```

## Features

- Business onboarding (submit website URL)
- Campaign management dashboard
- Lead review & approval interface (human-in-the-loop)
- Outreach tracking & analytics
- Real-time notifications
